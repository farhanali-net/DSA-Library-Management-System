# Project Overview

## Problem

A small library needs a simple way to manage book records without using a
fixed-size array.

## Solution

The application stores each book in a node of a singly linked list. The list
supports insertion, deletion, searching, traversal, and availability updates.

## Core DSA Concepts

- Node-based data representation
- Singly linked list
- Dynamic memory allocation
- Pointer traversal
- Linear search
- Node insertion
- Node deletion

## Scope

This is an educational console application. It focuses on demonstrating DSA
concepts rather than building a production-ready library system.
